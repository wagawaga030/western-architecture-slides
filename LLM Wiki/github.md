# 看懂西式建築風格：古羅馬、哥德式與巴洛克

> **給初學者的建築觀察入門指南** — 從結構力學、光影氛圍到代表地標，一次掌握西方三大經典建築風格。

本專案是一份基於 **LLM Wiki 知識庫工作流** 與 **嚴格忠實度審查（Fidelity Lint）** 製作的單一檔案互動式 HTML 教學簡報。所有教學內容皆可回溯至證據卡與原始參考資料，並將 AI 補充的教學比喻與 SVG 示意圖進行明確隔離標示。

## 🌐 線上預覽簡報（GitHub Pages）

## 🎯 簡報內容亮點（共 14 頁）

* **時代演進與導覽（P01–P02）**：涵蓋古羅馬、哥德式與巴洛克的時間軸 SVG 示意圖，並提醒建築風格並存與內外不一致的判讀原則。
* **三大風格深度解析（P03–P11）**：
  * **古羅馬建築**：火山灰混凝土、券拱與穹頂、模數化柱式，搭配羅馬競技場與萬神殿（上帝的眼睛）內嵌 SVG 結構示意圖。
  * **哥德式建築**：尖肋拱頂、飛扶壁結構原理、彩繪花窗，搭配飛扶壁力學支撐與巴黎聖母院立面 SVG 示意圖。
  * **巴洛克建築**：戲劇性光影、動態起伏立面、四分視投影（Quadratura），搭配凡爾賽宮中軸線與台灣仿巴洛克老街街屋 SVG 示意圖。
* **橫向對照與實戰辨識（P12–P13）**：三大風格輪廓並排比較圖、多維度綜合對照表，以及初學者 3 步驟實戰辨識決策樹流程圖。
* **隨堂互動小練習（P14）**：提供看地標猜風格的互動式問答（支援點擊顯示／隱藏答案）與核心速記口訣總回顧。

## 🛡️ 資料嚴謹度與審查機制

為確保教學內容「零幻覺」且來源透明，本專案遵循以下製作規範：

1. **資料分級標示**：所有引用皆標註原始來源可靠度等級（**A 級**：維基百科條目；**B 級**：建築教育專文；**C 級**：單一比較來源，於頁面附上黃色警示框提醒）。
2. **寧缺毋濫原則**：原始資料未展開建造年份或構造細節的 8 座地標，一律列入「不講清單」並註記「待後續資料補充」，不擅自以外部知識腦補。
3. **AI 補充嚴格隔離**：所有教學比喻、打卡看點、速記口訣與 9 張內嵌 SVG 示意圖，均明確標註 `AI 補充` 或 `示意圖（AI 補充，非原始來源，不代表精確比例）`，且圖上文字嚴格限定於證據卡既有詞彙。
4. **多輪忠實度審查與人工抽查**：完成逐句原檔比對、獨立審查員覆核及關鍵字搜尋抽查（完整細節詳見 `deck/report.md`）。
